# ProjectSettings

![Unity Logo](https://your-image-url.com)  
A base Unity setup using MVC architecture with Dependency Injection (VContainer), UniRx, and UniTask.

## 🚀 Features
- MVC pattern
- Dependency Injection with VContainer
- Reactive programming with UniRx
- Async operations with UniTask

## 🛠 Installation
```sh
git clone https://github.com/softituz/ProjectSettings.git
cd ProjectSettings
```

### Dependencies
Add the following dependencies to your Unity project:
```json
"com.cysharp.unitask": "https://github.com/Cysharp/UniTask.git?path=src/UniTask/Assets/Plugins/UniTask",
"com.neuecc.unirx": "https://github.com/neuecc/UniRx.git?path=Assets/Plugins/UniRx/Scripts",
"jp.hadashikick.vcontainer": "https://github.com/hadashiA/VContainer.git?path=VContainer/Assets/VContainer#1.16.8"
```

### Run the Project
1. Open Unity and load the project
2. Install dependencies (if not installed automatically)
3. Press Play

## 📖 Usage
1. Use VContainer for dependency injection
2. Use UniRx for reactive data flow
3. Use UniTask for async operations
